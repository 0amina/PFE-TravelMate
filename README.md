# PFE TravelMate — Property Rental Platform

TravelMate is a property rental platform developed as a final-year academic project.

## Project Structure

- `travelmate/` — Flutter mobile application.
- `admin/frontend/` — React administration panel built with Vite.

## Technologies

### Mobile Application
- Flutter
- Dart
- Firebase

### Administration Panel
- React
- JavaScript
- Vite

## Getting Started

### Flutter Application

1. Install Flutter and the required development tools.
2. Navigate to `travelmate/`.
3. Run `flutter pub get`.
4. Configure the required Firebase services.
5. Run the application using `flutter run`.

### React Admin Panel

1. Install Node.js.
2. Navigate to `admin/frontend/`.
3. Run `npm ci`.
4. Run `npm run dev`.
